# PATIENT-FLOW · 患者旅程（v0.1 草案，0 访谈改写句）

> 声明：本项目 0 患者访谈。以下旅程是按指南原件与公开资料构建的设计假设，"改写句"不是一手引语，不冒充患者原话。每条待访谈验证。

## 旅程总览（确诊后视角）
1. **确诊期**（第 0–4 周）：皮肤科病房或门诊明确诊断（临床表现+病理+免疫指标）。患者带着一叠化验单与出院小结回家，分不清"抗 Dsg3"和"抗 Dsg1"哪个重要。
2. **初始治疗期**（第 1–8 周）：大剂量激素起步（按医嘱），观察新发水疱是否停止、糜烂是否愈合。口腔疼痛影响进食，体重下降。副作用开始出现（血糖/血压/睡眠/情绪）。
3. **减量期**（第 2 个月–数年）：激素逐步减量，每 2–4 周复诊。最怕两件事：减快了复发、副作用扛不住。需要记清"这次减到多少、下次什么时候查什么"。
4. **长期维持与复发应对**（1–5 年）：低剂量长期维持。偶发新发水疱时的第一反应是"是不是要加回去"，需要按医生原话行动而不是自我判断。
5. **就诊准备**（贯穿）：复诊前把化验变化、用药变化、新发皮损整理成一页带去。

## 关键情绪节点（假设，待访谈）
- 确诊时：病名陌生（"天疱疮"常被误听为"湿疹/疱疹"），需要一层说清是什么、不是什么。
- 减量时：减量决定权在医生，患者想看"上次减量后有没有变化"来说服自己安心。
- 复发时：新发水疱出现当天最焦虑，需要"记录下来 + 按医嘱联系"，不需要自我诊断。

## 一次任务的步骤（核心线：记录一次复查并准备复诊）
输入：一张新化验单（ELISA 指数）、医生口头医嘱（剂量调整）→ 动作：录入指标（候选核对）、登记剂量变化、标记发作/缓解状态 → 输出：指标卡趋势更新、减量记录链新增一版、复诊准备清单可导出 → 失败恢复：录错可更正（新增版本不覆盖）、日期未知显式留空 → 成功标准：复诊时能打开一页说清"最近一次化验、最近一次减药、有没有新发水疱"。
