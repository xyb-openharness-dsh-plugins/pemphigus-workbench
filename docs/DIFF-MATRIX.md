## 重名率实测（M1 完成后填数）
- 对照移植样板 pericarditis v0.2：一级导航 9 项对照，同名 6/9 = **66.7%（实测 2026-11-11 00:20，≤70% 达标）**。同名项为家族通用页（看板/化验与趋势/就诊准备/报告与原件/病情档案/临床）；病种差异项为「发作与皮损」「用药与减量」「生活与情绪」。
- 二级页差异：meds 组三页「剂量与减量/输注登记/日常用药」（pericarditis 为「按次登记/日常用药」）；flares/labs/visits/reports/records/clinical 形同义换。
- 结论：结构同形、语义全换（心包/CRP/积液/秋水仙碱 → 水疱/ELISA 指数/糜烂/糖皮质激素减量链），跨仓残留 grep 0 命中为准（M2 末复跑）。
