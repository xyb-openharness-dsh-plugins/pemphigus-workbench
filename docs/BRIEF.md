# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：天疱疮（寻常型/落叶型）患者及家属照护者；处于糖皮质激素或免疫抑制剂治疗与减量期、关注抗体指数与复发迹象的患者；患者组织志愿者协作使用

场景：抗 Dsg1/3 抗体 ELISA 指数周期复查档案（标注方法与机构可比组）；糖皮质激素剂量调整与减量记录链；发作—缓解区间带（新发水疱/黏膜糜烂起止与累及部位）；评分量表按医生原文记录；口腔与皮肤分部位感受与指标并置；复诊问题清单与资料准备

核心流程：
1. 选择本机资料目录并导入化验单/出院小结/皮肤科随访记录
2. 核对候选信息，建立抗体指数档案与用药记录链
3. 记录发作与缓解（新发水疱、黏膜糜烂起止日期与累及部位）
4. 整理激素减量过程与复查节奏
5. 生成复诊准备与问题清单

完成结果：得到来源可追溯、可核对的天疱疮个人病程档案：抗体指数趋势、减量记录链、发作—缓解时间线、复诊准备材料；所有候选信息经用户核对入档；解读归医生

初始布局选择：business-first
