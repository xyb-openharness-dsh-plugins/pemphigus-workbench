# CLINICAL-DATA · 临床数据与医学边界（v0.1 草案）

## 内容边界（指南只定内容边界，不转自测或选治疗）
- 唯一 L1 原件：《86 个罕见病病种诊疗指南（2025 年版）》第 58 章 天疱疮（目录页 346–349，PDF 第 350–353 页）。
  - 来源：国务院政策文件库 https://www.gov.cn/zhengce/zhengceku/202507/P020250710595668350272.pdf
  - 下载核验：200 / application/pdf / 15,611,195 字节 / 517 页 / PDF 1.7（2026-11-10 夜间实测，与白塞病仓核验记录一致）
  - 章节：概述 / 病因和流行病学 / 临床表现 / 辅助检查 / 诊断 / 鉴别诊断 / 治疗 / 诊疗流程（图58-1）/ 参考文献
- 指南中的诊断标准、治疗方案只作"背景理解"与疾病概要内容，不生成"你符合/不符合标准""你应该用什么方案"的第③层判断。
- 阈值与求助短语在未过临床审核前一律【待核】占位。
- L2 题录（未取得全文，只记条目）：中国天疱疮诊疗指南（2024 版）DOI 10.35541/cjd.20240222；天疱疮患者健康教育共识（2023 版）DOI 10.35541/cjd.20230123；寻常型天疱疮诊断和治疗专家建议（2020）中华皮肤科杂志 2020,53(1):1-7；Schmidt E, et al. Pemphigus. Lancet 2019;394(10201):882-894；Murrell DF, et al. J Am Acad Dermatol 2020;82(3):575-585。
