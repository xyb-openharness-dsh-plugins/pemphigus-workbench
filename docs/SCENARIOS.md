# SCENARIOS · 场景清单（v0.1 草案）

> 每条挂"患者关心的信息维度"，医生任务不冒充患者需求。0 访谈：场景为设计假设，逐条待访谈验证。

## S1 发作与缓解记录（核心线）
- 患者：新发水疱/黏膜糜烂出现或消退时，记录起止日期与累及部位（口腔/皮肤/鼻/眼/生殖器）。
- 功能：发作—缓解折叠卡（起止日期、累及部位、医生原文）；距上次发作天数、近 90 天发作次数由数据派生显示，不落库。
- 验收：A/B 档案切换不串档；折叠卡收展实测；无"发作第 N 期"表述。

## S2 抗体指数与化验趋势线
- 患者：想看"上次减量前后抗体指数怎么变"，看懂化验单。
- 功能：指标卡按方法/单位/机构可比组分组（抗 Dsg1 ELISA、抗 Dsg3 ELISA 各自成组）；一图秀同一目录；单点不连线。
- 验收：MT01–MT15 抽测；C1–C12 抽测；不同方法不合并同屏声明。

## S3 治疗按次记录线（激素减量链）
- 患者：每次复诊医生调整剂量，回家后想记清"这次改成多少、从哪天开始"。
- 功能：剂量调整记录（医生原文 + 日期 + 药名），更正=新增版本；利妥昔单抗/IVIG 输注按次登记。
- 验收：IP8 无裸删除；同一药物事实层只有一条版本链；不做"建议剂量"。

## S4 就诊准备线
- 患者：复诊前一晚把近况整理成一页。
- 功能：复诊准备清单（最近化验、最近剂量变化、发作近况、想问的问题）；导出真实文件。
- 验收：导出文件格式真实可打开；私密条目被过滤并标注"N 条中私密 M 条"。

## S5 疾病理解线（疾病概要 DP）
- 患者："天疱疮到底是什么？跟类天疱疮差在哪？"
- 功能：顶栏 ? + 首页文字按钮双入口；四段（定义→医学资料规范和指南情况→治疗全景→发展趋势）；每段来源行四态。
- 验收：P1–P9 全过（probe-disease-primer --url 实测本原型）；固定出口"按受累器官与病情轻重排列"+"不代表任何一项适合你"+"需要问你的医生"。

## S6 生活影响线（口腔进食/皮肤照护/情绪）
- 患者：口腔疼得吃不下饭，想说清"从哪天开始影响进食"。
- 功能：身体感受与指标面两列并置（不写因果不写处置）；生活影响按日期记录。
- 验收：提醒只在两侧齐备时出现（paired/labsOnly 读模型判定）；无因果句。

## S7 资料与隐私线
- 患者：化验单原件照片、出院小结存档，有些记录不想让家人看到。
- 功能：文件登记（M6 前不解析内容）；私密标记逐版本携带；导出/AI/摘要三出口过滤。
- 验收：Q35–Q36 抽测；公开→私密→公开历史链正确。

## S8 试验信息线（35 号四段链路）
- 患者：听说有新药试验，想知道怎么查、证据链长什么样。
- 功能：建档→双通道检索→分层加证据链→候选线索；禁匹配指数与判读列。
- 验收：检查器进 check 链；FAILED 如实记录。

## 孤儿页与暂缓项
- 暂缓：MinerU 解析抽取（默认未接入，见 DEV-REQUIREMENTS §五.3）。
- 不做：疾病活动度自评打分、剂量建议、复发预测。
