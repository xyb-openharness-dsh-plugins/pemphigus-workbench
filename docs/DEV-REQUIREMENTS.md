# DEV-REQUIREMENTS · 开发需求与硬约束（v0.1）

## 一、家族基线（不可让步）
令牌先于组件；正文 15px/行高 1.65–1.68、等宽数字；三段外壳（原型声明条→侧栏→顶栏+页脚）；按钮 42–44px；类名词汇 .card/.pill/.notice/.empty/.table-wrap/.section-title；阴影只给浮层；口径文案同屏（「仅回顾，不解读」「解读归医生」「不同方法不合并」）；空状态给下一步按钮；私密三出口同一过滤函数；AI 输出永远是候选/预览；断点 1180/900/600。

## 二、非肿瘤语义（反例即失败）
- 不出现：病期/分期、治疗线序、疗效应答、预后、生存期、MRD/缓解深度评分、复发危险度分层。改用：发作—缓解区间（新发水疱/黏膜糜烂起止日期 + 累及部位）、按次剂量调整记录、受累部位维度（口腔/皮肤/鼻/眼/生殖器）。
- 指标卡不写升降级箭头，写「较上次」或「近 30 天中位数」，不暗示好坏；抗体指数是活动相关化验，必须标注方法/单位/机构可比组，不同方法不合并。
- 剂量记录只录医生原文（如"泼尼松 40mg/d，4 周后减 5mg"），阈值一律【待核】；不做"你应该减到 X"的推导。
- 提醒只用患者与医生已确认的行动计划原话（"若出现新发水疱或发热，联系 Y 医生"），不写"你已进入 XX 期"。

## 三、数据与隐私
ORDER BY rowid、显式 null、in_use、分节 *_title、分类不进趋势；演示唯一源（demo-data.js 双档案）；无判读列（diagnosis/risk_level/activity_score 不入库）；派生值读时算不落库（距上次发作天数、近 90 天发作次数）；私密标记逐版本携带，三出口（导出/AI 上下文/摘要预览）代码级过滤。

## 四、AI 与宿主
agent-draft 一键携带事实上下文（无判定词），只填不发；未接入态明说；customFrame + 右侧原生面板 25–45% 可拖；props.service 与 ctx 区分；接入失败先取客户端真实异常。

## 五、可回退默认值（夜间无人值守，待晨审追认）
1. 服务主体：天疱疮（寻常型/落叶型为主）患者本人 + 家属照护者。
2. 病程覆盖：从确诊后初始治疗到长期减量维持（不覆盖确诊前鉴别诊断阶段）。
3. MinerU 报告解析：默认未接入，导入线只做文件登记，不抽取数值（沿用 18 号合同，接入时再启用）。
4. 品牌名：小愈宝 HealPal（占位，用户可改名）。
5. 评分量表：仅按医生原文记录 PDAI 等量表结果，不内置自测。
6. 试验线：按 35 号四段链路实现（天疱疮有在研试验）；禁匹配指数与判读列。
7. NMPA 适应证状态：利妥昔单抗在天疱疮的适应证按"指南推荐但中国说明书适应证待核"处理，晨审复核。

## 六、提交前门禁
npm run check 全绿（SKIP 不计覆盖）；npm test 全过；audit 数字照抄；版本四处同源；三态汇报（实测/骨架/未实现）。
