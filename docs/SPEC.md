# SPEC · 小愈宝 HealPal 天疱疮工作台 v0.1

状态：草案（0 访谈、0 临床审核，待 G1 签认后升级）。签认人/日期：待补。

## 设计者与研究依据
设计者角色：面向天疱疮患者与家属的记录工具设计；调研以 L1 指南原件（《86 个罕见病病种诊疗指南（2025 年版）》第 58 章，已核验直链）为医学边界，公开患者叙述仅作 L3 分层素材；研究方法、证据分层见 USER-RESEARCH；取舍原则：记录与就诊准备优先，一切判定性输出不做。DESIGN-REVIEW 由独立评审轮次补足（G2）。

## 问题、用户与最小闭环
- 用户：天疱疮（寻常型/落叶型为主）患者及家属照护者（画像见 USER-RESEARCH）。
- 问题：减量期长（3–5 年）、复查项多（抗体指数+并发症筛查）、发作（新发水疱/糜烂）与减量的关系说不清。
- 最小闭环：录入/核对一次复查（指标候选+剂量医嘱+发作状态）→ 看板与趋势联动 → 复诊准备导出 → 复诊后回录医生答复。失败恢复：录错走更正版本链；日期未知显式留空。
- 成功标准：复诊时一页说清"最近化验、最近减药、发作近况"。

## 方案与 ADR
- ADR-1 布局：customFrame 整页工作台 + 右侧原生 AI 面板（25–45% 可拖）。备选（标准分栏）被否：看板+五 Tab 需要整页宽度和原生面板共存。
- ADR-2 趋势主指标：抗 Dsg1/3 ELISA 指数为趋势核心（指南：滴度与严重程度和活动度基本平行）；激素剂量不做曲线合并，做按次记录链（剂量是医嘱事实不是连续测量）。
- ADR-3 发作语义：发作—缓解区间带（起止日期+累及部位），非肿瘤不套分期；"距上次发作天数/近 90 天次数"读时派生。
- ADR-4 演示数据：单源 demo-data.js 双档案（A 刚确诊记录少 / B 两年随访发作与指标都多），切换整页联动。
- 宿主能力表：DSH Desktop customFrame + 面板契约按 docs/02 与 40 号；本机核验在 M6，未核验项不写通过。
