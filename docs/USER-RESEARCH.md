- P2 落叶型天疱疮患者，黏膜受累罕见，主诉集中在皮肤糜烂与结痂、日晒加重；长期外观困扰。

## 痛点排序假设（无访谈，仅作设计排序依据，不做统计宣称）
1. 减量期不知道"上次减到多少、接下来查什么"（对应 S3/S4）。
2. 化验单上的抗体指数看不懂趋势（对应 S2）。
3. 新发水疱出现时不知道该记什么、何时联系医生（对应 S1）。
4. 口腔疼痛/进食影响说不清楚（对应 S6）。
5. 就诊时间短，说不清近况（对应 S4）。

## 与家族既有仓的对照结论
- 复发性心包炎：发作—缓解 + 炎症指标（CRP/ESD 同形）→ 本仓移植其结构，指标换为 ELISA 指数与可比组口径。
- 白塞病：黏膜受累（口腔溃疡）叙事与本仓口腔糜烂高度相似 → 参考其黏膜记录维度，但白塞病是血管炎复发性口腔溃疡，与本仓棘层松解性水疱机制不同，不混用。
- 乳腺癌：抄卡片/最近报告表版式，不抄肿瘤标志物话术。
